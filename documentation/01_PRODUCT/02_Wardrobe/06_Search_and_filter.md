# Search, Filter & Discovery

> **Helping users quickly find and rediscover everything they own.**

---

# Purpose

The Wardrobe module should make every clothing item easy to locate.

Searching is only one part of the experience.

Users should also discover forgotten garments, identify wardrobe patterns and better understand their clothing collection.

---

# Search

Users can search using:

- clothing name,
- category,
- brand,
- color,
- material,
- season,
- occasion,
- tags.

Search results should update immediately.

---

# Smart Search

The wardrobe supports natural language search.

Examples:

- "black dresses"
- "summer clothes"
- "white sneakers"
- "business outfits"
- "red clothes for Christmas"

AI may translate user intent into filters.

---

# Filters

Users can filter by:

- category,
- subcategory,
- color,
- season,
- occasion,
- material,
- brand,
- favorite,
- archived,
- recently added,
- recently worn,
- never worn,
- AI confidence.

Multiple filters may be combined.

---

# Sorting

Supported sorting methods include:

- newest first,
- oldest first,
- alphabetical,
- most worn,
- least worn,
- recently used,
- color,
- brand.

---

# Collections

Wardrobe supports curated collections.

Collections may be:

- user-created,
- automatically generated,
- AI-generated.

Examples:

- Capsule Wardrobe
- Travel
- Favorites
- Business Wear

---

# Discovery

The Wardrobe should actively help users rediscover clothing.

Examples:

- forgotten garments,
- seasonal reminders,
- underused clothing,
- duplicate items,
- wardrobe balance insights,
- missing essentials.

Discovery should feel helpful rather than intrusive.

---

# Empty Results

When no clothing matches the current query:

- explain why,
- offer filter adjustments,
- suggest similar items,
- allow clearing filters.

Users should never reach a dead end.

---

# Performance

Search and filtering should feel instantaneous.

Users should receive immediate feedback after changing filters or entering search text.

# Closing Statement

Finding clothing should never become a task in itself.

The Wardrobe module should help users locate what they need while continually revealing new value within the clothing they already own.
