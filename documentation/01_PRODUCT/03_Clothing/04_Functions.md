# Clothing Metadata

> **The complete information model describing an individual clothing item.**

---

# Purpose

Metadata transforms a clothing item from a simple image into a meaningful digital object.

Each metadata attribute contributes to better organization, more accurate AI recommendations and richer user experiences across Szafnik.

Metadata should describe reality as accurately as possible.

---

# Metadata Principles

Clothing metadata follows these principles:

- Each attribute has one clear meaning.
- Information should never be duplicated.
- AI may suggest values.
- Users always have final control.
- Metadata should be easy to update over time.

---

# Core Metadata

Every clothing item should define:

- Name
- Category
- Subcategory
- Clothing Type

These attributes identify what the garment is.

---

# Visual Metadata

Visual characteristics include:

- Primary Color
- Secondary Colors
- Pattern
- Style
- Fit
- Sleeve Length
- Garment Length
- Neckline (when applicable)

These attributes help both browsing and AI recognition.

---

# Physical Metadata

Physical properties include:

- Brand
- Size
- Material
- Fabric Composition
- Condition

These attributes describe the real garment.

---

# Usage Metadata

Usage-related metadata includes:

- Suitable Seasons
- Suitable Occasions
- Formality Level
- Recommended Temperature Range
- Weather Suitability
- Waterproof Status

These attributes support planning and recommendations.

---

# Lifecycle Metadata

Each clothing item may store:

- Purchase Date
- Purchase Price
- Store
- Current Status
- Archive Status

Lifecycle metadata evolves together with the garment.

---

# AI Metadata

AI-specific metadata may include:

- Recognition Confidence
- Recognition Date
- AI Model Version
- User Corrections
- Recognition Source

These attributes improve future recognition while remaining transparent.

---

# Optional Metadata

Additional optional information may include:

- Notes
- Favorite
- Collections
- Personal Tags

Optional metadata should enhance organization without becoming mandatory.

---

# Metadata Quality

A high-quality clothing item should:

- contain complete metadata,
- accurately represent the real garment,
- remain up to date,
- support reliable AI recommendations.

Metadata quality directly affects the quality of the entire Szafnik ecosystem.
