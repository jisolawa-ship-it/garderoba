# Clothing Functions

> **Everything users can do with an individual clothing item.**

---

# Overview

The Clothing module manages the complete lifecycle of a single garment.

Its functions focus on creating, maintaining and improving the digital representation of one physical clothing item.

---

# Clothing Creation

Users can create a Clothing item by:

- taking a photo,
- selecting an image from the gallery,
- importing an existing image,
- creating an item manually.

Every new clothing item begins its lifecycle here.

---

# Recognition

Recognition-related functions include:

- AI clothing detection,
- attribute recognition,
- confidence estimation,
- metadata suggestions,
- user verification.

Recognition always requires user approval before saving.

---

# Metadata Management

Users can:

- edit metadata,
- update categories,
- modify colors,
- change materials,
- assign seasons,
- assign occasions,
- manage tags,
- update brands.

Metadata should evolve together with the real garment.

---

# Photo Management

Users can:

- add photos,
- remove photos,
- replace photos,
- reorder photos,
- select the primary image.

Photos should accurately represent the current appearance of the garment.

---

# Lifecycle Management

Users can:

- archive clothing,
- restore clothing,
- mark clothing as donated,
- mark clothing as sold,
- mark clothing as discarded.

Lifecycle changes should preserve historical information whenever appropriate.

---

# Usage Tracking

Each clothing item supports:

- wear history,
- wear count,
- last worn date,
- related outfits,
- related calendar events.

Usage information improves AI recommendations over time.

---

# AI Assistance

AI may assist by:

- suggesting missing metadata,
- identifying duplicate garments,
- detecting incomplete information,
- recommending better photos,
- comparing with similar wardrobe items.

AI never modifies clothing automatically.

---

# Relationships

A Clothing item may be used by:

- Outfits,
- Calendar,
- AI Stylist,
- Shopping,
- Family.

The Clothing module remains responsible for the garment itself.

---

# Maintenance

Users can:

- review clothing quality,
- complete missing information,
- update outdated metadata,
- maintain accurate digital records.

Every function within the Clothing module exists to ensure that each digital garment remains an accurate, complete and trustworthy representation of its real-world counterpart throughout its entire lifecycle.
