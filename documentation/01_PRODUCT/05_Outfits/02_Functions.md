# Outfits Functions

> **Everything users can do with saved outfits inside their personal outfit library.**

---

# Overview

The Outfits module manages outfit compositions that users have decided to preserve.

Its purpose is to organize, maintain and reuse successful styling decisions across the Szafnik ecosystem.

---

# Outfit Management

Users can:

- save outfits,
- edit saved outfits,
- rename outfits,
- add descriptions,
- duplicate outfits,
- archive outfits,
- delete outfits.

All changes affect the saved outfit while preserving references to Clothing items.

---

# Organization

Users can organize outfits using:

- collections,
- custom categories,
- favorites,
- tags,
- sorting options.

Organization should help users quickly find the right outfit.

---

# Reuse

Saved outfits can be:

- worn again,
- duplicated,
- opened in the Dressing Room for editing,
- used as templates for new outfits.

The goal is to maximize the value of previously created outfit combinations.

---

# Outfit Insights

Each outfit may provide information such as:

- wear count,
- last worn date,
- seasonal usage,
- associated occasions,
- favorite status.

Insights help users better understand how their outfit library evolves over time.

---

# AI Assistance

AI may assist by:

- suggesting better outfit names,
- identifying similar outfits,
- detecting duplicate combinations,
- recommending forgotten outfits,
- proposing updated outfit versions when clothing changes.

AI recommendations remain optional.

---

# Calendar Integration

Users can:

- schedule outfits,
- verify clothing availability,
- reuse outfits for future events,
- reschedule planned outfits.

Calendar integration supports efficient planning without duplicating outfit data.

---

# Family Support

Where appropriate, users may:

- share selected outfits,
- prepare outfits for children,
- coordinate family outfit collections.

Family functionality respects Privacy by Design.

---

# Archive & Lifecycle

Users can:

- archive outfits,
- restore archived outfits,
- preserve historical outfit records.

Outfits remain part of the user's styling history even when no longer actively used.

---

# Maintenance

Users can:

- remove obsolete outfits,
- refresh outdated combinations,
- update outfits after wardrobe changes,
- maintain a clean and useful outfit library.

# Closing Statement

The Outfits module preserves the user's best styling decisions and makes them easy to organize, revisit and adapt over time.

Every saved outfit should remain a valuable, reusable part of the user's personal styling library.
